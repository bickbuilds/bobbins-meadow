# Bobbin's Meadow

Bobbin's Meadow is a free math game for young children who are still learning to read. Bobbin and the meadow friends lead short, picture-first games: counting berries, number trails, river jumps, equal groups, repeating patterns, a gentle friend arena, and Make a monster. Every prompt is read aloud, and there are no timers.

**Play:** https://bickbuilds.github.io/bobbins-meadow/

The game is one self-contained `index.html`. It works best in Safari on an iPad, and also runs in Chrome, Edge and Firefox.

## Privacy

- **Saves stay in the browser.** Progress is kept in this browser's local storage on this device, with a small cookie copy as a backup. Monster idea cards and any recordings are kept in this browser too. Nothing is uploaded, and there are no accounts, ads or analytics. Clearing this site's data removes the progress. **Game settings → Saves and backups** can export a save file.
- **No network calls.** The page loads everything it needs from this one file and contacts no other server.
- **The microphone** is used only when a child taps the microphone in Make a monster, to record a name, story or sound. The recording stays on the device.
- **Name to text is off by default.** When a parent turns it on in **Game settings**, the workshop uses Safari's speech recognition to turn a spoken monster name into text. Apple's speech service may process that spoken name. With it off, a spoken name is kept as a voice bubble.

## Voices

All spoken lines are computer-generated, not recordings of a person. Most use the Piper LJ Speech voice; some use OpenAI text-to-speech voices. See [NOTICE](NOTICE) for credits and licenses.
